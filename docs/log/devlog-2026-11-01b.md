# Devlog — 1 Nov (evening): Heartwood from bosses, gentler costs, 4K

*Itch devlog for the html5-dev build pushed from `main` (aad928f) on 1 Nov 2026 (itch run 41299645890). Posted: https://veniceissinking.itch.io/elves-vs-orcs/devlog/1744474. It covers everything since the morning build (4667644).*

This build changes how runs grow. Heartwood is now earned by beating bosses rather than collected on every fall, so each run's skill tree matters more.

## What's new
- **Heartwood comes from bosses.** A fallen wall now pays a flat 1 Heartwood. The rest drops from boss waves: 3 at wave 25, 6 at wave 50, and so on.
- **Bosses every 25 waves.** They were every 50, so the first boss arrives much sooner.
- **No passive Heartwood bonus.** Heartwood no longer adds +12% to everything just by being earned. You spend it on the Heartwood tree, and that is where its power comes from.
- **Gleaning moved deeper.** It now sits under War Drums in the Grove branch, with 5 ranks of +8% starlight (was 10 ranks of +15% right off the root). It was an easy first buy that snowballed every run.
- **Gentler upgrade costs.** Past wave 10, node prices now rise ×1.1 per wave instead of ×1.25, so runs no longer stall in the mid-teens. In our test runs the first boss is reached after about an hour and a half of play.
- **4K screens.** The interface, text and skill tree now scale with the window, from a laptop up to 3840×2160, and stay crisp.
- **Fixes.** Damaged barricade planks no longer flicker; each plank now breaks at a fixed point as the wall loses health. Older saves are now tested against every past version, so they keep loading.
