## Launch trailer (TB-278; first logged as TB-277, which main gave to the progression stall)
- director (26 Nov, decision cards): trailer by scripted in-game capture; "first you need to fully plan and storyboard the idea"; storyboard approved ("Approve it"), music B.
- Rig: headless Chromium on the dev build with Playwright's page clock paused, stepped 1/30 s per frame, screenshot per frame, so footage is smooth on any machine (~0.15 s per 1080p frame here). Scenes are set up through the real intents: nodes can only be bought while the run is fallen, so setup marks the run fallen, buys, then replants. `soften(k)` scales orc hits so a held line never falls mid-shot.
- Learned: a pinned wall health via setInterval cannot stop a fall at wave 40+, since one tick of 160 orcs can take half the wall; scale orc attack instead. The fallen overlay outlives a wipe; hide `#fallen` between scenes. Boss shot strength: bow 5, companions 3, armoury 2, vanguard 3 kills the wave-25 Warboss ~12 s after it appears, mid-field.
- Draft 1 rejected outright (wide static view, HUD on, tiny sprites, cuts off the beat). Take 2 rebuilt from scratch: `rig2.mjs` draws the field canvas at 3x and crops it with a virtual camera (world x, y, zoom), so close-ups are native resolution; health bars, wave strip, crit words and loot pillars are off and loot numbers are throttled; every frame logs positions and sim events to meta.json. `edit2.py` cuts on music B's librosa beat grid (91.3 BPM), anchoring in-points to logged events (the strike lands on the beat); `audio2.py` lays the game's own SFX from those events, ducks the music under the big hits and normalises to -14 LUFS, -1 dBTP.
- Review: `review2.py frames` (a still every 0.5 s at full size) and `review2.py sound` (momentary loudness and spectrogram with cut marks). Two full passes found an empty boss shot, a ballista too small to read (cut), loot pillars in close-ups, a page crop through text and a frost shot that ran out of frames; all fixed before sending.
- Learnt: a held wall needs a floor (`__tr.wallFloor`), not only softened orcs: in long warm-ups the wave still breaks it, the run freezes and a summoned boss never appears. Never wait on capture runs with `while pgrep -f ...`: the pattern matches the waiter's own command line.
